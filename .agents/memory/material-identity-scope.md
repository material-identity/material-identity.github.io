name: Material Identity content and scope
description: Standing product scope and terminology for the documentation site.
---

Material Identity is an open-source, vendor-neutral project publishing JSON schemas for material declarations. This draft is a standalone static documentation website, suitable for later export to GitHub Pages. No backend, database, login, pricing, forms, or sales.

**Why:** The user explicitly set this scope.

**How to apply:** Keep future site work hard-coded and static unless the user changes the scope. Preserve the GitHub documentation/Primer appearance rather than introducing marketing imagery or styles.

Describe all schemas as open source under a copyleft licence. The Global Schema is the most generic, universal schema for any declaration; Metals, Chemicals and Forestry Material Schemas have narrower definitions. Existing industry standards retain their identity and ownership.

**Why:** The user explicitly required these distinctions.

**How to apply:** Keep these statements consistent in introductory content and schema documentation. Use “machine-interpretable” when discussing meaning. Do not describe schemas as approved or certified, attribute artificial intelligence features, introduce material-passport terminology, display forestry JSON examples, or link to legacy repositories or schema hosts excluded by the user. Retain the community logos.
