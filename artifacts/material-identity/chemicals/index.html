Purpose

Manufacturers deliver a certificate of analysis with every batch. This schema replaces PDF and proprietary EDI formats with open, extensible JSON. It was developed with BASF, a fittings manufacturer and S1SEVEN, and released as open source.

Structure at a glance

SectionContents
CertificateLanguages, identifier, date, standard (e.g. EN 10204 3.1)
PartiesManufacturer, customer, optional receiver
BusinessTransactionOrder, optional order confirmation, delivery
ProductIdentifier, name, origin, batch identifiers, dates, standards
AnalysisInspections: property, method, value, value type, min, max, unit, test conditions
DeclarationOfConformanceDeclaration, optional CE marking
DisclaimerLegal disclaimer text
AttachmentsFiles embedded with a hash
ContactsResponsible contact persons

Key features

  • Standardized CAMPUS property identifiers recognize a property regardless of how its method is spelled; property names are translated via the identifiers.
  • Attachments carry a hash: test curves, processing instructions based on OPC and EUROMAP, data sheets.
  • Standardized layout for PDF and HTML.
  • Rendering in one or two languages.

Tools

  • Validation against the JSON schema, with valid and invalid test fixtures.
  • Rendering of any declaration as standardized PDF and HTML.
  • Localization in one or two languages, with localized numbers and dates.
